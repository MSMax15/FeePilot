FOMO 10% fee discount: what it actually means

Current public offer: FOMO's referral pages currently advertise 10% off fees for eligible users who enter a referral code in-app.

If an eligible FOMO platform fee is $50, a 10% reduction would save $5, leaving $45. If a fee is $5, the same 10% reduction would save $0.50.
