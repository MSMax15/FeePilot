Can you add a FOMO referral code after signup?

Short answer: FOMO's public referral pages explain entering a referral code in-app for a fee benefit, but they do not clearly guarantee that every already-created account can attach a code retroactively.

Because the public documentation is not explicit on retroactive referral attachment, the safest route is to use the referral link before signup and verify the benefit inside FOMO.

If you already made an account

  1. Open your profile/referral area in FOMO.
  2. Look for a place to enter or confirm a referral code.
  3. If available, use LMP506 and check whether the benefit appears.
  4. If there is no option, ask official FOMO support rather than assuming the discount is active.

Why this matters

FOMO's current public referral pages say users can get 10% off fees by entering a code in-app. That makes the account-level confirmation more important than relying on a third-party website.
